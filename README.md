# ServiceFlow · Landing page

Landing page institucional do **ServiceFlow**, sistema desktop para gerenciamento de serviços, clientes, profissionais e agendamentos.

A página apresenta o sistema, explica sua finalidade e destaca as principais funcionalidades, seguindo a mesma identidade visual do aplicativo: tons escuros, textos claros e azul como cor de destaque.

## Tecnologias

- **HTML5:** estrutura e conteúdo.
- **CSS3:** estilização, layout, responsividade e animações.
- **JavaScript puro:** interações da interface.

Nenhum framework, biblioteca ou recurso externo é utilizado.

## Seções

- **Header:** logo e menu de navegação (com menu lateral em telas menores).
- **Início:** apresentação do ServiceFlow com prévia ilustrativa do dashboard.
- **Sobre:** finalidade do projeto e áreas do sistema.
- **Funcionalidades:** Dashboard, Agenda, Clientes, Serviços, Profissionais e Relatórios.
- **Diferenciais:** principais vantagens do sistema.
- **Footer:** descrição, links, créditos e direitos reservados.

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.

Não é necessário instalar dependências nem usar um servidor.
